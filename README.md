# kydhtml

큰 글씨, 파스텔 색, 선 아이콘을 사용하는 인터랙티브 HTML 연수자료 제작용 Codex 스킬입니다. 새 수업자료를 만들거나 기존 HTML 슬라이드에 개념 설명, 실습, 체험 링크를 추가할 수 있습니다.

## 다른 Codex에 설치하기

Codex에 다음 문장을 입력하세요.

```text
$skill-installer로 https://github.com/vkfks8524-pixel/kydhtml/tree/main/skills/kydhtml 스킬을 설치해줘.
```

수동으로 설치하려면 저장소를 내려받아 `skills/kydhtml` 폴더 전체를 사용자 홈의 `.agents/skills/`에 복사하세요. 프로젝트에서만 사용하려면 프로젝트 폴더의 `.agents/skills/`에 복사하세요. [Codex 스킬 경로 안내](https://developers.openai.com/codex/skills)

## 사용하기

설치 후 새 Codex 대화에서 `$kydhtml`과 함께 주제, 대상, 원하는 실습을 알려 주세요.

```text
$kydhtml 중학생에게 웹의 프론트엔드와 백엔드를 설명하는 HTML 슬라이드를 만들어줘.
마지막에 버튼을 눌러 요청과 응답 흐름을 체험하는 장을 넣어줘.
```
